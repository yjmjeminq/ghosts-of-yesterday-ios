# 본편 연속성

| 범위 | 사건과 상태 |
| --- | --- |
| 1~7 | 2년 전 임무 피해와 은퇴. 월요일 밤 윤은 베란다에서 부상당한 스파이더우먼을 돕고 가면을 확인하지 않는다. 화요일에 그웬만 윤을 알아본다. 지도, 건포도 농담, 금요일 공연, 함께 찍은 사진이 두 사람 사이에 남는다. |
| 8~14 | 손목의 상처와 움직임, 가방, 연락이 끊기는 시각을 본 윤이 9화에서 독자적으로 확신한다. 영화 메시지는 지우고, 데이트를 거절했을 때 그웬은 답을 존중한다. |
| 15~21 | 15화 베란다 치료에서 윤이 이름을 부른다. 그웬은 윤이 알았다는 사실만 확인한다. 그웬이 20화에 먼저 고백하고, 21화 첫 정식 데이트에 서로 동의한 입맞춤을 한다. |
| 22~28 | 밴드, 장보기, 순찰 일정, 생일. 윤은 조직 연락을 거절한다. 레버넌트는 킹핀의 심부름과 다른 동기로 윤을 찾아온다. |
| 29~35 | 레버넌트는 충격을 받은 만큼 저장하고, 방출한 팔은 잠시 움직이지 못한다. 33화 그웬은 시민을 먼저 대피시키고, 윤이 순간이동으로 방출을 대신 맞은 뒤 레버넌트가 팬텀이라고 부른다. 그웬의 구조를 받은 윤이 생존한다. |
| 36~42 | 회복 중 윤은 실제 범죄와 은퇴의 계기를 말한다. 그웬은 신뢰와 책임을 구분한다. 검은 힘을 받아들인 그웬은 윤의 도움을 받되 자신이 방출과 추격을 중단한다. 둘은 비밀과 일방적 희생을 반복하지 않기로 한다. |
| 43~47 | 고정 링·이동 링, 미리 확인한 화물문 좌표, 초록등 세 번과 신호를 앞에 심는다. 시민과 증거를 먼저 내보내고 케인·머독은 체포된다. 그웬은 미리 합의한 좌표 및 거미줄을 이용해 윤을 구조한다. |
| 48~50 | 윤은 변호인과 함께 증거를 제출하고 유죄를 인정해 복역과 후속 조건을 이행한다. 시간이 흐른 뒤 재회해 집을 만들고, 베란다와 처음에 했던 현관 농담을 회수한다. |
