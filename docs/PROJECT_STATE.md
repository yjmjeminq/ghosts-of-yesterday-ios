# 프로젝트 상태

## Windows 1.0.1 · 전편 검수판

50화, 366장면, 대사·내레이션 3,735줄이 포함된 Windows 배치 빌드다. 빌드 폴더의 리소스에 최신 런타임 대본이 바이트 단위로 동일하게 포함됐음을 확인했다. 직전 빌드의 저장 ID 2,827개와 저장 별칭 159개의 도착 줄, 갤러리 키 15개를 유지했다. 가장 긴 대사·내레이션은 85자다.

타이틀의 이어 읽기와 불러오기, 본편의 빠른 저장·불러오기와 수동 슬롯 6칸, 이전 저장 형식 마이그레이션, 손상 파일 복구, 갤러리 해금 도달을 에디터 배치 검사에서 확인했다.

## 원고와 아트

8~19화는 장면과 인물 행동을 보강했다. 20~50화는 기존 확장판을 바탕으로 대사의 중복, 시간, 부상과 공간 이동, 증거 소품을 교정했다. 회차당 최소 글자 수는 사용자 지시에 따라 완료 기준에서 제외했다. 설정집의 고정 사건과 공개 순서는 유지했다.

1600×900 웹툰 JPG 22장과 포즈 스프라이트 3개가 포함된다. 41장면에 별도 스프라이트를 합성한다. 배경과 포즈의 사용 장면은 ASSET_MANIFEST.json에 있다. 베란다의 낙하, 처치, 재방문 포즈는 오프라인 합성 시트에서 확인했다.

## 검증

- 대본 컴파일, 원고·JSON 동기화, 릴리스 검사, Unity Windows 배치 빌드 통과.
- 빌드 로그는 qa/RUNS/build-windows.log, 독립 검수 및 후속 교정 기록은 qa/PARTS_2_TO_8_EXPANSION.md.
- 사용자 요청에 따라 게임 실행과 Unity Play Mode는 진행하지 않았다. 실제 플레이 화면·입력·음향과 모바일 설치는 미검증이다.
