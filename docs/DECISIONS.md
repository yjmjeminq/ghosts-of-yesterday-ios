# 제작 결정

- 설정집의 50화 구조와 비밀 공개 순서를 그대로 사용했다. 윤과 그웬의 도시사 과제, 레버넌트의 차고 습격 세부, 연구 시설의 고정·이동 링은 새로 정했다.
- 윤의 책임은 증거 제출과 유죄 인정, 실제 복역, 후속 조건 이행을 거쳐 표현했다. 형량을 특정하지 않고 49화 전 수년이 지났음을 보여 준다.
- 그웬의 흑백 일체형 슈트, 흰 전면 마스크, 슈트의 어깨에 연결된 흰 후드와 그 안쪽의 분홍 거미줄 무늬를 공통으로 사용한다. 자세별 투명 레이어를 배경과 분리하며, 거즈 인서트도 같은 장갑으로 맞췄다. 일상에서는 금발 단발과 버건디 재킷을 사용한다.
- 작품 속 연구 장치는 허구의 소품이다. 프로필은 기존 안정적인 대사 ID와 슬롯 배열을 함께 사용한다. 브랜치 없이 한 번의 완결된 스토리만 제공한다.
- 진행 검증에는 사용자 요청을 반영해 배치 에디터, 정적 데이터와 합성 이미지 확인을 사용했다.
